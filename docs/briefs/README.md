# Implementation briefs

A brief specifies one unit of work precisely enough that an independent session
can execute it without access to the conversation that produced it. Scope,
interfaces, acceptance criteria and — critically — what is *out* of scope.

The template and the rules are in [`../AGENT_HANDOFF.md`](../AGENT_HANDOFF.md).
